A one-line pickup line written to charm a robot or an AI: "Are you a CAPTCHA? Because you just proved you're not a robot — and baby, I'd click every traffic light for you." One line, 112 characters, written by `main.py` to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
